Як це працює?

Від формування накладної до підтвердження магазином — весь ланцюжок автоматизований.

📦 Приходна накладна

1
Дистриб'ютор формує накладну
В обліковій системі або через API ScanCount. Накладна потрапляє в хмару з унікальним штрихкодом OUT-XXXXXX
Бухгалтер
2
Експедитор отримує маршрут
В app.html з'являється список накладних на доставку. Геолокація фіксується при кожній дії.
Експедитор
3
Магазин сканує штрихкод
Відкриває накладну камерою або вручну вводить номер. Може скоригувати кількість товарів.
Магазин
4
Підтвердження отримання
Статус накладної змінюється на confirmed. Дистриб'ютор бачить підтвердження в реальному часі.
✓ Завершено

↩ Повернення від магазину

1
Магазин ініціює повернення
Сканує штрихкод товару → вводить кількість → натискає "Накладна на повернення"
Магазин
2
Експедитор сканує при забірці
В app.html відкриває "Повернення" → сканує штрихкод RET-XXXXXX → підтверджує
Експедитор
3
Товарознавець обробляє
Отримує повернення в чергу → перевіряє товари → підтверджує або коригує кількість
Товарознавець

Для магазину

Магазин отримує безкоштовний доступ до переобліку і друку цінників одразу після реєстрації. Платні функції вмикаються кодом від дистриб'ютора.

Реєстрація
✓ Безкоштовно назавжди — переоблік і друк цінників не потребують підписки.
1
Відкрийте scancount.online → натисніть Реєстрація
2
Виберіть Реєстрація магазину — заповніть назву, телефон, ім'я власника, email і пароль
3
Після реєстрації з'явиться ваш унікальний код магазину — SHOP-XXXXXX. Збережіть його.
4
Відкривається кабінет магазину з переобліком, цінниками та сканером накладних
Переоблік товарів
Як це працює: Скануєте штрихкод → система шукає назву в базі → вводите кількість → додаєте до переобліку. В кінці зберігаєте CSV.
1
Натисніть кнопку 📷 або введіть штрихкод вручну в поле сканування
2
Якщо товар знайдено в базі — назва підставляється автоматично (українською)
3
Введіть кількість → натисніть + Додати
4
Після завершення натисніть Зберегти → отримаєте CSV файл з переобліком
⚠️ Щоб завантажити власну базу товарів — підготуйте CSV у форматі: штрихкод;назва;одиниця;ціна
Друк цінників
1
Натисніть 🏷 Друк цінників в кабінеті або відкрийте scancount.online/price-tags.html
2
Скануйте штрихкоди товарів → введіть ціну для кожного
3
Натисніть 💾 Зберегти PDF → відкриється діалог друку
4
Формат: A4, до 24 цінників 58×40мм на аркуші. Розрізати по лініях.
Підключення дистриб'ютора
1
В кабінеті магазину прокрутіть до розділу Мої дистриб'ютори
2
Натисніть + Додати дистриб'ютора → введіть код DIST-XXXXXX який надав дистриб'ютор
3
Після підключення з'являться папки: Приходні, Повернення, Коригувальні накладні
Сканування накладної
1
Натисніть 📷 Сканувати накладну в кабінеті
2
Відскануйте штрихкод OUT-XXXXXX який показує експедитор або введіть номер вручну
3
Перевірте список товарів — за потреби скоригуйте кількість
4
Натисніть ✓ Підтвердити отримання — накладна закривається
// 04

Для дистриб'ютора

Кабінет головного бухгалтера на scancount.online — центр управління всією логістикою. Реєстрація через email/пароль.

Початкове налаштування
1
Відкрийте scancount.online → Реєстрація дистриб'ютора → заповніть дані компанії
2
Після реєстрації отримаєте код DIST-XXXXXX — передайте його магазинам для підключення
3
14 днів безкоштовного пробного періоду — після цього потрібна підписка
Управління персоналом
Головний бухгалтер генерує коди для всіх співробітників. Кожен отримує унікальний код STAFF-XXXXXX для входу в app.html.
1
Вкладка Співробітники → + Додати співробітника
2
Введіть ім'я, телефон, роль (товарознавець / експедитор) → система генерує код автоматично
3
Передайте код STAFF-XXXXXX співробітнику — він вводить його в app.html для входу
4
Бухгалтер (app.html) може вмикати/вимикати активність кожного співробітника
Черга товарознавців
1
Вкладка Черга — показує всі накладні що очікують обробки товарознавцем
2
Накладні розподіляються автоматично між активними товарознавцями
3
Статус кожної накладної відображається в реальному часі
Моніторинг магазинів
1
Вкладка Магазини — список всіх підключених магазинів з кодами SHOP-XXXXXX
2
Для кожного магазину — кількість накладних і час останньої активності
3
Код магазину використовується для тарифікації — скільки магазинів підключено
// 05

Для експедитора

Мобільний інтерфейс оптимізований для роботи однією рукою під час завантаження та розвантаження. Геолокація обов'язкова.

Вхід по коду
1
Відкрийте scancount.online/app.html → виберіть Експедитор
2
Введіть код EXP-XXXX або STAFF-XXXXXX який надав бухгалтер → Увійти
3
Дозвольте доступ до геолокації — без неї система не дозволить підтверджувати доставки
Сканування повернення
1
Головний екран → Повернення
2
Натисніть на зону сканування → наведіть камеру на штрихкод RET-XXXXXX магазину
3
Перевірте список товарів → натисніть Підтвердити забірку
4
Геолокація фіксується автоматично → накладна закривається
Коригування накладної
1
Головний екран → Коригування
2
Відскануйте штрихкод коригувальної накладної COR-XXXXXX
3
Внесіть зміни в кількість → Зберегти коригування
⚠️ Без активної геолокації підтвердження неможливе — перевірте налаштування телефону.
// 06

Для товарознавця

Товарознавець — сполучна ланка між обліковою системою і реальністю. Отримує накладні в чергу, звіряє і підтверджує.

Вхід та черга
1
Відкрийте app.html → Товарознавець → введіть код MRC-XXXX або STAFF-XXXXXX
2
Відкривається список накладних призначених вам бухгалтером
3
Натисніть на накладну → перевірте товари → підтвердіть або внесіть правки
Вхідні повернення
1
Вкладка Повернення — показує всі повернення підтверджені експедитором
2
Перевірте фізичну наявність товарів → підтвердьте або відхиліть
// 07

API інтеграція

REST API для інтеграції з обліковими системами (1С, M.E.Doc та ін.). Базовий URL: https://scancount-api.scancount-service.workers.dev

Автентифікація
POST /v1/auth Content-Type: application/json { "dist_code": "DIST-XXXXXX", "api_key": "ваш_ключ" } Response: { "token": "Bearer eyJ...", "expires_in": 86400 }
Ендпоінти
POST/v1/invoices— Створити накладну
GET/v1/invoices/{id}— Отримати накладну
PATCH/v1/invoices/{id}— Оновити статус
GET/v1/invoices?store={code}— Список накладних магазину
Створення накладної (POST /v1/invoices)
{ "store_code": "SHOP-XXXXXX", "type": "incoming", "items": [ { "barcode": "4820001234567", "name": "Молоко 1л", "unit": "шт", "qty": 10, "price": 45.90 } ] } Response: { "id": "OUT-7X9K2M", "barcode": "OUT-7X9K2M", "status": "pending" }
Статуси накладних
СтатусОпис
pendingСтворена, очікує доставки
in_deliveryЕкспедитор взяв в роботу
deliveredДоставлена, очікує підтвердження магазином
confirmedМагазин підтвердив отримання
cancelledСкасована
