Що таке
ScanCount?

ScanCount — це платформа для автоматизації документообігу між магазинами і дистриб'юторами. Накладні, повернення, коригування — все в хмарі, з геолокацією і штрихкодами.

Ключова ідея: Дистриб'ютор формує накладну у своїй системі → вона автоматично через API потрапляє в ScanCount → експедитор отримує на телефоні → сканує штрихкод → підтверджує або коригує → магазин підтверджує отримання. Все збережено в хмарі.

Для
магазину

Магазин отримує безкоштовний доступ до переобліку і друку цінників одразу після реєстрації. Платні функції вмикаються кодом від дистриб'ютора.

Реєстрація

01
Відкрийте scancount.online
На головній сторінці натисніть кнопку Реєстрація. Виберіть тип акаунту — Магазин.
02
Заповніть дані
Введіть телефон, email, назву магазину та ім'я власника. Натисніть Зареєструватись.
03
Готово — безкоштовні функції доступні
Одразу доступні: Переоблік і Друк цінників. Без жодного коду.

Переоблік товарів

01
Відскануйте або введіть штрихкод
В полі сканування введіть штрихкод або натисніть 📷 для сканування камерою. Товар знаходиться автоматично з бази 151к+ позицій.
02
Введіть кількість і ціну
Після сканування вкажіть кількість і роздрібну ціну. Товар додається в таблицю переобліку.
03
Товар не знайдений — введіть вручну
Якщо штрихкод не знайдено в базі — введіть назву і одиницю виміру вручну. Товар автоматично зберігається в локальну базу вашого магазину. При наступному скануванні цього штрихкоду — назва підтягнеться автоматично.
04
Збережіть переоблік
Натисніть Зберегти — результат переобліку збережеться на пристрій. База товарів вашого магазину зберігається локально і поповнюється автоматично при кожному новому скануванні.

Друк цінників

01
Перейдіть в розділ Друк цінників
На головній сторінці натисніть 🏷️ Друк цінників.
02
Відскануйте товари
Скануйте штрихкоди — для кожного товару вкажіть роздрібну ціну.
03
Збережіть PDF і роздрукуйте
Натисніть Зберегти PDF — отримаєте аркуш A4 з 24 цінниками 58×40мм. Після друку розріжте по лініях.
База товарів: Загальна база (151к+ позицій) поповнюється постачальниками — ви отримуєте оновлення автоматично. Товари які ви додали вручну зберігаються тільки у вашому магазині.
Порада: Цінники містять штрихкод для внутрішнього використання — зручно для подальшого сканування при переобліку.

Підключення дистриб'ютора

01
Отримайте код від дистриб'ютора
Дистриб'ютор генерує код в своєму кабінеті (Налаштування → Код для магазинів). Формат: DIST-XXXXXX
02
Увійдіть в кабінет магазину
Після входу натисніть + Додати дистриб'ютора → введіть код → система автоматично заповнить картку дистриб'ютора.
03
Платні функції активовані
Автоматично відкриються три папки для кожного дистриб'ютора: ↩ Повернення ✏️ Коригування 📦 Приходні

Сканування накладної

01
Отримайте накладну від експедитора
Коли експедитор доставив товар і підтвердив накладну, на ній є штрихкод. Відкрийте кабінет магазину → 📷 Сканувати накладну.
02
Відскануйте або введіть номер
Наведіть камеру на штрихкод або введіть номер накладної вручну (наприклад OUT-ABC123XY).
03
Перевірте і підтвердіть
Система покаже список товарів. Якщо є коригування від експедитора — вони відображені окремо. Натисніть ✓ Підтвердити отримання.
04
Накладна збережена в папку
Приходні → в папку Приходні накладні. Накладні з коригуванням → в папку Коригування. Повернення, які ви відправили раніше → в Повернення.
// 04

Для
дистриб'ютора

Кабінет бухгалтера на app.scancount.online — центр управління всією логістикою дистриб'ютора.

Початкове налаштування

01
Відкрийте app.scancount.online
Виберіть роль Бухгалтер → введіть код BUH-XXXX або увійдіть як адміністратор.
02
Заповніть реквізити
Налаштування → Реквізити компанії. Заповніть: назва, ЄДРПОУ, ІПН, адреса, банк, IBAN, МФО, телефон, email.
03
Скопіюйте код для магазинів
Після збереження реквізитів система генерує Код для підключення магазинів формату DIST-XXXXXX. Надайте його магазинам.
04
Налаштуйте API інтеграцію
Скопіюйте API ключ і передайте програмісту вашої облікової системи (1С, SAP, тощо). Він підключить автоматичне відправлення накладних.

Управління персоналом

Принцип роботи: Бухгалтер створює акаунти. Кожен співробітник отримує унікальний код входу. Коди зберігаються в Firebase і перевіряються при вході.
01
Додайте товарознавця
Меню Товарознавці → + Товарознавець → введіть ім'я і телефон → система генерує код MRC-XXXX. Збережено в Firebase.
02
Додайте експедитора
Меню Експедитори → + Експедитор → ім'я і телефон → код EXP-XXXX. Скопіюйте код — передайте водію.
03
Активація/деактивація
В таблиці персоналу є toggle перемикач. Деактивований співробітник не може увійти в систему — зручно при звільненні або лікарняному.

Для
експедитора

Мобільний інтерфейс. Оптимізований для роботи однією рукою під час завантаження/розвантаження.

Вхід по коду

01
Відкрийте app.scancount.online
Виберіть роль 🚗 Експедитор.
02
Введіть код
Введіть код формату EXP-XXXX який надав бухгалтер. Система перевіряє код в Firebase — якщо активний, пускає.

Сканування повернення

01
Натисніть "📷 Сканувати накладну"
На головному екрані дві великі кнопки. Для повернення від магазину — перша кнопка.
02
Відскануйте штрихкод накладної
Натисніть на зону сканування або введіть номер вручну. Система завантажує накладну з Firebase.
03
Підтвердіть з геолокацією
Натисніть ✓ Підтвердити з геолокацією — браузер запросить дозвіл на геолокацію. Координати зберігаються в Firebase разом з підтвердженням.
Важливо: Геолокація — обов'язкова. Вона підтверджує що підтвердження відбулось фізично в магазині, а не дистанційно. Дайте дозвіл браузеру при першому запиті.

Коригування накладної

01
Натисніть "✏️ Внести коригування"
Друга велика кнопка на головному екрані — для приходних накладних де є розбіжності.
02
Завантажте накладну
Відскануйте штрихкод або введіть номер. Накладна завантажується з Firebase з усіма позиціями товарознавця.
03
Відредагуйте кількість або найменування
В таблиці позицій — змініть кількість або назву товару де є фактична розбіжність. Змінені рядки підсвічуються помаранчевим.
04
Відправте з геолокацією
Натисніть 📤 Відправити з геолокацією. Firebase зберігає: оригінал, поправки, diff і координати. Товарознавець отримує сповіщення.

Для
товарознавця

Товарознавець — сполучна ланка між обліковою системою і реальністю. Він отримує накладні в чергу, звіряє поправки і вносить в свою систему.

Вхідні повернення

01
Увійдіть як Товарознавець
Відкрийте app.scancount.online → виберіть 📋 Товарознавець → введіть код MRC-XXXX.
02
Перегляньте вхідні повернення
Розділ ↩ Вхідні повернення — список накладних від магазинів підтверджених експедитором. Бачите геолокацію підтвердження.
03
Натисніть Розглянути і внесіть в систему
Перевірте позиції. Натисніть ✓ Внесено в систему — накладна позначається як оброблена.

Поправки від експедитора

01
Розділ "Мої накладні"
Тут видно всі відправлені вами накладні зі статусами: 🚗 У дорозі / ⚠️ Є поправки / ✓ Підтверджено.
02
Перегляньте поправки
Натисніть Переглянути поправки — таблиця показує що було / що стало / різниця по кожній позиції.
03
Прийміть або відхиліть
✓ Прийняти — внесіть зміни у свою облікову систему і підтвердіть. ✗ Відхилити — накладна повертається експедитору.

API
інтеграція

Для адміністраторів облікових систем (1С, SAP, Excel, власні рішення). Один ендпоінт — і накладні автоматично потрапляють в ScanCount.

Base URL: https://scancount-api.scancount-service.workers.dev

Автентифікація

Всі POST і PATCH запити потребують заголовку X-API-Key. Ключ генерується в кабінеті бухгалтера → Налаштування → API ключ.

HTTP Headers
Content-Type: application/json
X-API-Key: sk_live_xxxxxxxxxxxxxxxx

Повний приклад — 1С інтеграція

Node.js приклад
// Відправка накладної в ScanCount при друці в 1С
async function sendInvoiceToScanCount(invoice) {
const response = await fetch(
'https://scancount-api.scancount-service.workers.dev/v1/invoices',
{
method: 'POST',
headers: {
'Content-Type': 'application/json',
'X-API-Key': process.env.SCANCOUNT_API_KEY
},
body: JSON.stringify({
store_id: invoice.storeId,
items: invoice.lines.map(line => ({
barcode: line.barcode,
name: line.name,
qty: line.quantity,
unit: line.unit
}))
})
}
);
const data = await response.json();
// data.barcode_url — URL штрихкоду для друку
// data.num — номер накладної
return data;
}
