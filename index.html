🏭 Інструмент дистриб'ютора
Це платний функціонал для дистриб'юторів.

Що отримує дистриб'ютор:
📋 Кабінет бухгалтера — управління персоналом і звітність
👨‍💼 Кабінет товарознавця — обробка накладних і пересортування
🚗 Кабінет експедитора — підтвердження доставок з геолокацією
🔄 API інтеграція — накладні автоматично з вашої облікової системи
📦 Повернення і коригування — зі смартфону в реальному часі

Як це працює:
1️⃣ Дистриб'ютор підключає магазини через API
2️⃣ Накладна формується в обліковій системі і автоматично з'являється у водія
3️⃣ Водій сканує штрихкод, підтверджує з геолокацією
4️⃣ Якщо є розбіжність — редагує на місці, товарознавець бачить поправки

💰 Зв'яжіться з нами для підключення
📦 Як це працює для магазину
Повернення товару:
1️⃣ Ви формуєте накладну на повернення прямо тут
2️⃣ Приїжджає водій дистриб'ютора
3️⃣ Сканує штрихкод — система фіксує геолокацію
4️⃣ Товарознавець отримує підтвердження одразу

Приходна накладна:
1️⃣ Дистриб'ютор формує накладну у своїй системі
2️⃣ Вона автоматично з'являється у водія на телефоні
3️⃣ Якщо щось не збіглось — водій редагує на місці
4️⃣ Товарознавець бачить всі зміни з поясненням
